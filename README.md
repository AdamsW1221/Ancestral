# Ancestral 🕵️‍♂️

**Ancestral** es una herramienta que te permite verificar si tu información personal (como correos electrónicos) ha sido expuesta en filtraciones de datos conocidas. Con una interfaz intuitiva y un diseño moderno, Ancestral te brinda resultados rápidos y detallados sobre posibles brechas de seguridad.

![Captura de Ancestral](/img/app.jpg)  

---

## Características principales ✨

- **Validación de correo electrónico**: Asegura que el correo ingresado sea válido antes de realizar la consulta.
- **Consulta de filtraciones**: Utiliza la API de [XposedOrNot](https://xposedornot.com/) para obtener información sobre brechas de datos.
- **Visualización detallada**: Muestra los resultados en un formato claro y organizado, con acordeones para expandir/colapsar detalles.
- **Tema oscuro/claro**: Cambia entre modos de visualización para una experiencia personalizada.
- **Diseño responsive**: Funciona perfectamente en dispositivos móviles y de escritorio.

---

## Cómo usar Ancestral 🚀

1. **Ingresa tu correo electrónico**:  
   Escribe tu correo en el campo de texto y haz clic en "Send".

2. **Espera los resultados**:  
   Ancestral consultará la API y te mostrará si tu información ha sido expuesta en alguna filtración.

3. **Explora los detalles**:  
   Haz clic en cada resultado para ver más información, como el tipo de datos expuestos y la fecha de la filtración.

4. **Cambia el tema**:  
   Usa el interruptor en la esquina superior derecha para cambiar entre el modo claro y oscuro.

---

## Tecnologías utilizadas 🛠️

- **Frontend**: HTML, Tailwind CSS, JavaScript.
- **Backend**: VanillaJs
- **API**: [XposedOrNot](https://xposedornot.com/).
